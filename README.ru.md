# Exuvia

*Экзувий — шкурка, которую насекомое сбрасывает при линьке.*

Переключатель скинов для Hollow Knight: Silksong. Скины включаются и выключаются прямо в игре, из меню паузы или главного меню, без перезапуска.

Мод ставится один: нужен только BepInEx 5. Customizer, CustomizerT2D, CustomizerCinematic, Patchwork и Stitchwork для него не требуются, а скины, сделанные под них, он читает сам.

> Предварительная версия. Проверялась на одном ПК (Windows) и восьми скинах. Что именно проверено, а что нет — в разделе «Что проверено».

## Что умеет

- **Пункт «Скины» в меню игры.** Экран в стиле самой игры: список скинов, включить или выключить по нажатию, работает с клавиатуры, мыши и геймпада.
- **Без перезапуска.** Скин надевается и снимается на лету, включая меню, инвентарь и HUD.
- **Два формата скинов.**
  - Формат Customizer: атласы спрайтов (`Knight\atlas0.png` и т. п.), папка `Texture2D` (меню, интерфейс), папки `Video` / `VideoClip` (видео-заставки).
  - Формат Patchwork / Stitchwork: отдельные спрайты (`Sprites\...`), картинки `Sprites\T2D`, тексты (`Text`), звуки (`Sounds`), перекраска сцен (`Recolor`), условия по кресту и сцене (`conditions.json`).
- **Одна папка для скинов.** Кладёте в `<папка игры>\Skins` архив (zip, rar, 7z) или папку со скином — мод сам разбирает его при запуске игры и при открытии экрана «Скины». Скины так и остаются в `Skins`, по папке на скин; чтобы удалить скин, удалите его папку.
- **Превью.** Рядом со списком видна картинка выбранного скина: значок из архива, а если его нет — Хорнет в этом скине.
- **Без чужого кода.** Если в архиве скина лежит DLL автора, мод её не ставит и пишет об этом в подписи скина. Нужна — положите её в `BepInEx\plugins` сами.
- **Без замираний.** Картинки расшифровываются в фоновых потоках. Недавно выключенные скины остаются в видеопамяти про запас, поэтому повторное включение почти мгновенное.

## Установка

1. Установите [BepInEx 5](https://thunderstore.io/c/hollow-knight-silksong/p/BepInEx/BepInExPack_Silksong/) для Silksong.
2. Положите `Exuvia.dll` в `Hollow Knight Silksong\BepInEx\plugins\Exuvia\`.
3. Запустите игру. В главном меню и в меню паузы появится пункт «Скины».

Новые скины кладите в папку `Skins` (она появится в папке игры после первого запуска). Разобранный архив переезжает в `Skins\_installed` — для работы он не нужен, его можно удалить.

Скины, которые уже стоят в `Hollow Knight Silksong_Data\Mods\Customizer\`, `Packs\<имя>\Stitchwork` или `BepInEx\plugins\...\Stitchwork`, мод тоже видит — переносить их не нужно.

### Совместимость с другими модами для скинов

- **Customizer** — выключите его (`Customizer.dll`): он подменяет те же атласы.
- **CustomizerT2D, CustomizerCinematic** — не нужны. Если они стоят, Exuvia не мешает: меню с интерфейсом и видео-заставки остаются за ними.
- **Patchwork, Stitchwork** — не ставьте вместе с Exuvia: оба будут подменять одни и те же спрайты.

## Память и слабые ПК

Картинки скинов лежат в видеопамяти несжатыми — так устроены сами форматы скинов, с Customizer было так же. Большой скин с атласами и интерфейсом занимает около 1,1 ГБ видеопамяти, скин формата Stitchwork — около 0,4 ГБ.

Запас под недавно выключенные скины мод подбирает сам:

| Видеопамять | Запас |
|---|---|
| меньше 3 ГБ | нет |
| 4 ГБ | около 0,8 ГБ |
| 6 ГБ | около 1,2 ГБ |
| 8 ГБ и больше | 1,5 ГБ |

Без запаса скин при каждом включении загружается заново в фоне — это секунда-две без замираний. Число можно задать вручную настройкой `KeepRecentMB`.

## Настройки

Файл `BepInEx\config\sova.exuvia.cfg` (или F1, если стоит ConfigurationManager).

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `Keys / Menu` | `\` | Открыть запасное окно со списком скинов |
| `General / Language` | `auto` | Язык: `auto`, `ru`, `en` |
| `General / MenuButtons` | `true` | Пункт «Скины» в меню игры |
| `General / ExclusiveOnConflict` | `true` | Включение скина выключает скины, меняющие те же текстуры |
| `General / KeepRecentMB` | `-1` | Запас видеопамяти под недавние скины, МБ (`-1` — само, `0` — не держать) |
| `General / MaxCacheMB` | `1500` | Предел памяти под текстуры включённых скинов |
| `General / BackgroundDecode` | `true` | Расшифровка картинок в фоновых потоках |
| `General / LogFrameLoad` | `false` | Раз в 30 секунд писать в журнал нагрузку мода на кадр |
| `Stitchwork / Images, Texts, Sounds, Recolor` | `true` | Части скинов формата Stitchwork по отдельности |

## Что проверено

Проверено в игре: включение и выключение скинов обоих форматов из меню, меню и интерфейс скинов (папка `Texture2D`) без CustomizerT2D, установка из папки `Skins` (zip), фоновая загрузка, запас недавних скинов, видео-заставки, превью.

Проверено мало или не проверено: архивы rar и 7z, тексты, звуки и перекраска (только на одном скине), сборники из нескольких скинов в одном архиве, Linux и macOS.

## Чего мод не умеет

Из возможностей Stitchwork не сделаны: условия `area`, `act`, `boss`, `ability` (считаются невыполненными), замена целых текстур для мешей и частиц, шрифты, курсор, общие правила перекраски. Инструментов для авторов скинов (выгрузка спрайтов, редактор) в моде нет — для этого есть Patchwork и Stitchwork.

## Сборка

Нужен .NET SDK 8 и установленная игра с BepInEx.

```
dotnet build src/Exuvia.csproj -c Release -p:GameDir="<папка игры>"
```

Готовый файл: `src\bin\Release\netstandard2.1\Exuvia.dll`.

- Silksong Customizer — RatherChaoticDev. Формат скинов из атласов.
- CustomizerT2D — Su4enka. Правило сопоставления текстур меню и интерфейса.
- Custom Knight для Hollow Knight — идея переключать скины из меню игры.
